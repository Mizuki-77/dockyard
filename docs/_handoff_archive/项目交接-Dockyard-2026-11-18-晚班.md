## 4. 数据模型速查

层级：**class（舰级公共）→ ship（单舰差异）→ fact（时间窗 + 来源）→ narrative（多说法并列）**。

- 解析顺序：单舰 fact（窗口内）→ 舰级 fact（窗口内）→ 未记载。单舰命中即覆盖舰级，**不算分歧**。
- 主值规则：证据层级（A>B>C>D，E 不参与）→ 口径明确度 → 采集时间 → source id 字母序。主值只是默认显示，不是裁决。
- fact 硬规则：`field` 来自注册表；`valid: {from, to}` 必填（`to` 可空，需文件级 `open_ended_note`）；`src` 至少一个。
- `about: weapon:<id>` / `about: mount:<id>` 把 fact 归到武器/炮位实体。**单舰页「武器配置」的条目数从此抽出来**（见 `src/lib/data.ts:485` 的 `getEntities()`），只写在 slices 里的防空配置不会出现在那一栏。
- 排水量拆 `displacement.standard / .full / .deep` 三字段，不合并。

### 三条红线（从第一天起没变）

1. **有争议的说法一条不删**，留在 `note` 或进 narrative。删掉等于把网站的寿命锁死在今天的认知水平。
2. **推断值不进 `data/`**，只记可溯源的布尔事实；推算过程留 `work/`。
3. fact 的 `field` 必须是注册表里的；缺 `src` 或时间窗直接构建失败。


## 6. 已定判例（别再重新争论）

### 6.1 IWM 图片来源（2026-11-18 定）

| 情况 | 档位 |
|---|---|
| 原件藏 IWM、Commons 副本标 Public domain（英国战时官方摄影，Crown Copyright 已过期） | **A · 归档**，note 必须写 IWM 编号 + 出处说明 |
| 从 IWM 站内直接下载的副本 | **B · 外链**，不归档 |
| Commons 上找不到 PD 依据 / 署名要求 non-commercial | **C · 禁用** |

依据：`§5.4` 硬约束 1「授权跟着这张具体的数字化副本走」。本站已定无广告、无打赏、无周边。
**残留风险已知**：Commons 的 PD 标签是社区标注不是担保；FL 2425、A 29571 这两张的 Commons Credit 直接指向 `media.iwm.org.uk`，即上传者取自 IWM 站内。一旦发现误标，撤图改外链。

### 6.2 其他

- **缩略图宽度只允许** 120 / 250 / 330 / 500 / 960 / 1280 / 1920 / 3840（Wikimedia 白名单）。站里习惯用 1280。
- **Wikimedia unscaled 路径会返 429**，走 `iiurlwidth` thumb 节点才稳。
- **同名舰陷阱**：`work/raw/kgv/np-kgv.txt` 是 1912 年那艘；1939 年本体是 `np-kgv39.txt`。
- **NavWeaps 命名陷阱**：`navweaps-55in-50-mk1` 是 5.5 英寸，不是 5.25 英寸。

## 9. 环境与已知坑

- Windows + PowerShell 5.1；`npm.ps1` 被执行策略禁，**必须走 `cmd /c "npm.cmd ..."`**。
- PowerShell 输出中文会 GBK 乱码 → 用 read 工具读文件，别信控制台回显。
- 国内直连 `workers.dev`、NavWeaps（443 阻断）、de.wiki 都不通，需代理 `http://127.0.0.1:7897`（SakuraCat，`D:\sakuracat\SakuraCat.exe`，需手动开）。部署前后先 `Test-NetConnection 127.0.0.1 -Port 7897`。
- 截图：本机有 Chrome（`C:\Program Files\Google\Chrome\Application\chrome.exe`），可 `--headless=new --screenshot`。**输出路径不能含空格**（项目路径里有 "deepseek harness"，会报「系统找不到指定的路径」），先写到 `%TEMP%` 再拷回来。
- 页面有锚点 id：`#intro` / `#armament` / `#history` / `#timeline` / `#specs` / `#gallery`，截图定位用。
- Node 侧无 playwright / puppeteer，别指望跑 E2E。
