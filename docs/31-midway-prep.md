## 4. 航母专属必查项（现 5 舰没覆盖到的）

第一次做航母，这些容易漏：

| 项目 | 为什么中途岛必须查 |
|---|---|
| **机库层数** | 赤城三层甲板 vs 美舰单层大机库，这是设计哲学的核心对比 |
| **飞行甲板长度** | 日舰从战巡/战列舰底子改装，甲板比例与纯血航母不同 |
| **升降机数量与位置** | 影响出动率的硬指标 |
| **拦阻索** | 回收作业关键 |
| **舰载机编制（机型 + 数量）** | 零战/九九舰爆/九七舰攻 vs F4F/SBD/TBD。**TBD 几乎全灭**是战役转折 |
| **雷达有无与型号** | 日几乎无 / 美有 CXAM → **谁先发现对方** |
| **防空炮口径构成** | 25 mm vs 40 mm + 20 mm，火力密度差一个量级 |
| **舰桥/舰岛位置** | 赤城左舷（罕见）、飞龙右舷（与赤城相反，两舰设计曾互换） |
