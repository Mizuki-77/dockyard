## 4. 配图：11 张，全部按 Commons 分类浏览

### 4.1 遵守的三条硬规矩（交接报告 §7.4）

1. **绝对不用关键词搜索**，按 `Category:` 浏览。关键词会抓到图书馆封面、
   1904 年报纸、现代空军合影——上一轮踩过三次。
2. 每张之间 sleep 2-3 秒；遇 429 等 10-20 秒重试。
3. 缩略图宽度只用合法档位。

### 4.2 分类名必须验证

第一轮我猜的分类名（`Category:Type 96 25 mm AT/AA gun` 等）**全部 0 结果**。
`work/find_cats.py` 在 Category 命名空间里搜正名，才拿到：

| 武器 | 正确分类 |
|---|---|
| 25mm 九六式 | `Category:Type 96 25 mm machine gun` |
| 12.7cm 八九式 | `Category:Type 89 12.7cm AA Gun` |
| 20cm 三年式 | `Category:20 cm/50 3rd Year Type naval gun` |
| 1.1"/75 | `Category:1.1"/75 caliber gun`（11 个文件，全站最少） |

### 4.3 分类污染：必须人工看，不能只按尺寸排序

即使按分类浏览，里面也混着垃圾。`work/weaponimg_pick.py` 里有一份黑名单：

```
replica / AT-6 / Texan      ← a6m2 分类里有 3 张 AT-6 改装的「零战」
Hirohito / Emperor / 島村    ← 25mm 与 12.7cm 分类里混进昭和天皇照片
wreck / burning / damaged    ← 残骸与燃烧照片
```

最终 12 张**全部人工钉死**（`PICK` 字典），不靠自动规则。

### 4.4 一个技术发现：图床域名

上一轮 `11in75-mk1` 下载连续 429 失败，等了 5 分钟重试 20 次仍失败。

原因不是限流额度，而是**用错了域名**。Commons API 返回的 `thumburl` 在
`upload.wikimedia.org`，那个域对本站持续 429；改用 **`thumb.wikimedia.org`**
立刻成功。

> 以后抓 Commons 图优先用 `thumb.wikimedia.org`。
> 若必须用 `upload.wikimedia.org`，注意它会对 UA 与速率做更严的限制。

## 7. 原料本身的问题（subagent 报告，未裁决）

按项目规矩**只记录、不擅自改**，下一个接手的人需要知道：

1. **`ijn-weapons.md` §8-B 的「36 舰爆」与逐舰记录算不平**。
   合计栏写「36 B5N2 + 36 D3A1 + 36 A6M2」，但逐舰记录是
   赤城 18 + 加贺 18 + 苍龙 18 = **54 架 D3A1**。两个口径找不到能相加的组合。
   正文按「并列表述、不裁决」处理。
2. **§6-G「制式采用 1939-12」的引文不支持该结论**。引文
   `one month prior to its official acceptance` 只说「某件事发生在采用前一个月」，
   本身不给出采用月份。
3. **`ijen-weapons.md` §4-F 章节归类错误**：把利根/筑摩、榛名/雾岛的 25mm
   装备表列进了「中途岛四空母」标题下。
4. **`usn-weapons.md` §4.6「齐射重量 8.12 lb/s」口径不明**：按六挺 .50 反推约
   568 发/分，接近 M2 循环射速，但原料没说这是循环还是实战射速。
5. **§7.4 机高「9' 21"」是排印错误**（9 ft 21 in 不成立），原料自己标了。
6. **加贺 25mm 座数三说并存**：11 基 / 14 基 / 改装增装 4 基（11+4=15，14+0=14），
   来源没说这 4 基算在哪边。正文并列，明写「本站不替它算」。
